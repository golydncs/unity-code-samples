Spine Prefab Builder

Spine의 SkeletonDataAsset을 기반으로 캐릭터 프리팹 생성과 설정 작업을 자동화하는 Unity Editor 도구의 코드 샘플입니다.

작업 대상에 따라 두 가지 생성 방식을 제공합니다.

1. 필요한 그룹만 선택해 생성
   폴더 이름에 입력한 검색어가 포함된 폴더와 하위 폴더의 데이터로 프리팹을 일괄 생성합니다.

2. 전체 데이터를 비교해 누락된 프리팹 생성
   검색어와 관계없이 지정 경로의 전체 데이터를 기존 프리팹과 비교해, SkeletonDataAsset은 있지만 대응하는 캐릭터 프리팹이 없는 항목만 생성합니다.

두 기능은 각각의 버튼으로 실행하며, 캐릭터 계층과 애니메이션, 렌더러, 플랫폼별 텍스처 설정은 공통 생성 함수에서 적용합니다.

같은 데이터 파일의 중복 처리를 방지하고, 생성에 실패하면 작업 중인 오브젝트를 정리합니다.
